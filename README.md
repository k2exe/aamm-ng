## Project history

AAMM-NG is an independent, from-scratch implementation inspired by the
original AREDN Alert Message Manager (AAMM) project maintained by
Gerard Hickey, WT0F.

AAMM established useful prior art for managing all-node, group, and
node-specific AREDN Alert Messages through a web interface. AAMM-NG
preserves compatibility with the established alert-file conventions
while using a new implementation, security model, user interface,
API, and packaging system.

AAMM-NG does not contain source code, web assets, packaging scripts,
or other implementation material from the original AAMM repository.
