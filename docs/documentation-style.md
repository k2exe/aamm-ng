# Documentation Style

Use ASD-STE100 Simplified Technical English for AAMM-NG technical documentation.

Use ASD-STE100 Issue 9, January 2025, as the primary reference.

The project can adopt a later issue after review.

Apply these project rules:

- Use short sentences.
- Put one topic in each sentence.
- Use the active voice.
- Use direct instructions in procedures.
- Use the same term for the same item or action.
- Do not use unnecessary synonyms.
- Use simple and unambiguous words.
- Use American English spelling.
- Put a condition before an instruction when the reader must know the condition first.
- Use AREDN, AAMM-NG, OpenWrt, UCI, Linux, and other project terms as technical terms.
- Keep commands, paths, configuration names, hostnames, and protocol names exact.
- Do not change technical meaning to make text simpler.
- Do not claim that documentation is formally ASD-STE100 certified unless it received an appropriate formal review.

For procedures, give one action in each numbered step when practical.

Use descriptive text only when it gives information that the reader needs.

This guide supplements ASD-STE100. It does not replace the standard.

If this guide conflicts with ASD-STE100, use ASD-STE100.
